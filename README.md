# NEONVOID — Arena Survival

A neon arena survival shooter for the [make.fun best-game-01](https://make.fun/bounty/best-game-01) bounty. Blast the void swarm, chain kills for combo multipliers, grab upgrades between waves, and survive all 10 waves — including the VOID CORE boss every 5th wave.

## How to play

- **Move:** WASD or arrow keys
- **Aim:** mouse
- **Fire:** hold click or Space
- **Pause:** P or Esc — **Mute:** M — **Restart:** R
- **Upgrades:** click a card or press 1 / 2 / 3 after clearing a wave

Enemies: chasers hunt you, dashers telegraph and lunge, shooters fire from range, splitters burst into minis, tanks soak damage, and the VOID CORE boss fires radial bullet rings. Graze enemy bullets for bonus points; pick up health cells and overcharge drops.

## Run it

Serve `game/` with any static server and open `index.html` in desktop Chrome — no build step, no network requests, all art and sound are procedural.
